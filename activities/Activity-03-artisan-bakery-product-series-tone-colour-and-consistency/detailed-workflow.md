# Activity 03 - Artisan Bakery Product Series: Tone, Colour, and Consistency

**Course:** Mastering Adobe Lightroom for Photo Editing
**Course Code:** TGS-2022015367
**Alignment:** K1, K4, K5, A2, A3
**Version:** v12.0 | 19 August 2026

## Detailed Lightroom production workflow

### Before you begin

1. Work only on the supplied practice images or other images for which you have explicit permission.
2. Create an `evidence/` folder and preserve the source files unchanged.
3. Open the current Lightroom interface available to you; menu names can vary slightly across desktop, web, mobile, and Classic.
4. Save a screenshot whenever the workflow asks you to prove a setting, comparison, mask, search, permission, or export result.

### Procedure

1. Choose a representative hero frame and state the tonal, colour, crop, and mood problems before editing.
2. Apply an appropriate profile and correct white balance using a neutral reference or believable memory colour.
3. Read the histogram; set Exposure, Highlights, Shadows, Whites, and Blacks while checking clipping.
4. Use a gentle Tone Curve only if the tonal relationship still needs shaping.
5. Adjust Vibrance before Saturation; protect bread, packaging, and skin from implausible colour.
6. Use the Colour Mixer to refine only colours that distract from the intended palette.
7. Crop to the required menu aspect ratio and check edge distractions, negative space, and visual balance.
8. Add restrained Texture or Clarity at final viewing size; inspect for halos and excessive crunch.
9. Create a preset containing only repeatable global decisions, then apply it to the remaining images.
10. Adapt exposure, crop, and colour per frame instead of treating the preset as a finished edit.
11. Compare the set in grid view and correct any frame that breaks tonal or colour continuity.
12. Export a proof set and inspect the exported JPEGs for colour, crop, naming, and file size.

### Review with stakeholders

1. Present the before/after comparison and the evidence, not only the finished image.
2. Ask reviewers to respond against the brief and acceptance criteria.
3. Record the decision owner, requested change, approval status, and next action.
4. Retain rejected versions when they explain a material decision.

### Debrief questions

1. Which design principle guided your crop?
2. Why did Vibrance or Saturation suit this material?
3. What should the preset exclude?
4. How did you evaluate consistency without forcing identical values?
