# Activity 02 - Marina Bay Event Library: Cull, Organise, and Retrieve

**Course:** Mastering Adobe Lightroom for Photo Editing
**Course Code:** TGS-2022015367
**Alignment:** K1, K2, A1, A2
**Version:** v12.0 | 19 August 2026

## Detailed Lightroom production workflow

### Before you begin

1. Work only on the supplied practice images or other images for which you have explicit permission.
2. Create an `evidence/` folder and preserve the source files unchanged.
3. Open the current Lightroom interface available to you; menu names can vary slightly across desktop, web, mobile, and Classic.
4. Save a screenshot whenever the workflow asks you to prove a setting, comparison, mask, search, permission, or export result.

### Procedure

1. Import all supplied event photographs into one clearly named album and confirm the count.
2. Review each frame at fit view, then at 100% for focus, motion blur, noise, expressions, and distracting edges.
3. Reject only technical or storytelling failures; avoid using star ratings before the first rejection pass.
4. Apply Pick flags to frames that meet the brief, then use star ratings to rank the strongest alternatives.
5. Add consistent keywords for campaign, location, subject type, and rights/approval status.
6. Complete title, caption, copyright, creator, and usage-status metadata for the final candidates.
7. Use filters to isolate picked images rated three stars or above, then verify the result count.
8. Search using a keyword and a natural-language description; record whether both methods return the expected asset.
9. Create a final-selects album without duplicating or deleting the original files.
10. Present the six-image sequence and explain how variety, continuity, and rights status shaped the cull.

### Review with stakeholders

1. Present the before/after comparison and the evidence, not only the finished image.
2. Ask reviewers to respond against the brief and acceptance criteria.
3. Record the decision owner, requested change, approval status, and next action.
4. Retain rejected versions when they explain a material decision.

### Debrief questions

1. What makes a frame useful beyond sharpness?
2. Which metadata fields protect future reuse?
3. How do flags, ratings, albums, and keywords serve different decisions?
4. Can another editor reproduce your filtered selection?
