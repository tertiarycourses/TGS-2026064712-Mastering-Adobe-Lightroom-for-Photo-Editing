# Activity 06 - Tourism Image Rescue: Detail, Removal, and AI Enhancement

**Course:** Mastering Adobe Lightroom for Photo Editing
**Course Code:** TGS-2022015367
**Alignment:** K1, K2, K4, K5, A2, A3
**Version:** v12.0 | 19 August 2026

## Detailed Lightroom production workflow

### Before you begin

1. Work only on the supplied practice images or other images for which you have explicit permission.
2. Create an `evidence/` folder and preserve the source files unchanged.
3. Open the current Lightroom interface available to you; menu names can vary slightly across desktop, web, mobile, and Classic.
4. Save a screenshot whenever the workflow asks you to prove a setting, comparison, mask, search, permission, or export result.

### Procedure

1. Duplicate the edit version and record the original pixel dimensions, noise, sharpness, haze, and intended output size.
2. Correct lens issues and global tone before using enhancement tools.
3. Apply Dehaze cautiously and rebalance exposure, colour, and saturation affected by it.
4. Compare manual Noise Reduction with AI Denoise when available; inspect edges and fine texture at 100%.
5. Use Dust Removal or Heal for the sensor spot and verify that no real detail was removed.
6. Use the appropriate Remove mode for distracting people; include shadows when selecting and inspect every variation.
7. Compare standard sharpening with AI Sharpen when available; reject invented or brittle detail.
8. Run Generative Upscale at a suitable factor when available; create a stack and compare with a conventional export resize.
9. If the destination crop requires more canvas and Generative Expand is available, test it on a separate version and label generated content clearly.
10. Inspect faces, signs, railings, foliage, repeated patterns, seams, and edge transitions for artefacts.
11. Estimate whether the output meets the viewing-distance and pixel-dimension requirement.
12. Recommend use, restricted use, or rejection, and document the technical and authenticity reasons.

### Review with stakeholders

1. Present the before/after comparison and the evidence, not only the finished image.
2. Ask reviewers to respond against the brief and acceptance criteria.
3. Record the decision owner, requested change, approval status, and next action.
4. Retain rejected versions when they explain a material decision.

### Debrief questions

1. Which enhancement created real value?
2. Where did AI invent or damage detail?
3. What is the correct order for denoise, upscale, mask, and final export?
4. When should the image be rejected despite technical improvement?
